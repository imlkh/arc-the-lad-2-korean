# Korean Patching Guide - Arc the Lad 2

This document explains how to apply Korean translations to Arc the Lad 2 game files.

## Overview

The patching process involves two files:
1. **COMM.IMG** - Font texture containing character glyphs
2. **S*.STG** - Stage files containing dialogue text

The `patch_korean.py` script handles both:
- Injects Korean Hangul glyphs into the font texture
- Re-encodes Korean dialogue text into the stage files

## Prerequisites

1. **Python 3** with Pillow library:
   ```bash
   pip install Pillow
   ```

2. **Korean font glyphs** (pre-generated):
   ```
   output/font/korean/chars/char_XXXX.png
   ```
   These are 12x12 pixel Hangul glyph images generated by `python/font/generate_korean_font.py`.

3. **Translation file**:
   ```
   translated/ko/S100_STG.txt
   ```
   Korean translations in the standard format (see Translation File Format below).

## Usage

### Basic Usage

```bash
cd atl2_korean_translation
python python/patch_korean.py S100
```

This will:
1. Copy `S100.STG` → `output/patched/S100_KR.STG`
2. Copy `COMM.IMG` → `output/patched/COMM_KR.IMG`
3. Extract unique Korean characters from the translation
4. Inject Korean glyphs into `COMM_KR.IMG`
5. Re-encode Korean text into `S100_KR.STG`

### Dry Run (Test Without Writing)

```bash
python python/patch_korean.py S100 --dry-run
```

### Output Files

After patching, the following files are created in `output/patched/`:

| File | Description |
|------|-------------|
| `S100_KR.STG` | Patched stage file with Korean dialogues |
| `COMM_KR.IMG` | Font texture with Korean glyphs |
| `S100_charmap.txt` | Korean character → charID mapping |

## Font Slot Allocation

The patching preserves certain character slots and replaces others:

| CharID Range | Original Content | Action |
|--------------|------------------|--------|
| 1-80 | Hiragana (あ-っ) | **Replaced** with Korean |
| 81-160 | Katakana (ア-ッ) | **Replaced** with Korean |
| 161-186 | Latin A-Z | **Preserved** |
| 187-212 | Latin a-z | **Preserved** |
| 213-222 | Digits 0-9 | **Preserved** |
| 223-238 | Symbols (、。！？ etc.) | **Preserved** |
| 239+ | Kanji | **Replaced** with Korean |

This allows up to ~1,600 unique Korean characters while keeping Latin letters, numbers, and punctuation intact.

## Translation File Format

Translation files follow this format:

```
0x000B4516 [0x8006] [script:16 07]큰 도시네
0x000B4564 [0x8006] [script:44 07]알디아의 수도니까,[delay:15]그래서
--- context: 0x8006 -> 0x8005 ---
0x000B45C8 [0x8005] [script:72 07]여기가 내 아파트야
```

### Format Breakdown

| Component | Description |
|-----------|-------------|
| `0x000B4516` | File offset of the dialogue |
| `[0x8006]` | Speaker/context opcode |
| `[script:16 07]` | 2-byte event script prefix (preserved as-is) |
| Korean text | The translated dialogue |

### Supported Control Codes

| Tag | Bytes | Description |
|-----|-------|-------------|
| `\n` | `FF 05 01 01` | Line break |
| `[delay:XX]` | `FF 03 XX 01` | Text delay (XX = hex frame count) |
| `[box:system]` | `FF 08 01 01` | Open system text box |
| `[box:speech]` | `FF 08 03 01` | Open character speech box |
| `[box:close]` | `FF 08 02 01` | Close dialogue box |
| `[cursor]` | `FF 08 07 01` | Page break with cursor |
| `[opt]` | `EF` | Choice option prefix |

## Text Length Constraints

The game uses fixed-length dialogue slots. If a Korean translation is longer than the original Japanese text, it will be **truncated** to fit.

### Byte Comparison

| Character Type | Bytes |
|----------------|-------|
| Korean Hangul (charID 1-160) | 1 byte |
| Korean Hangul (charID 239+) | 2 bytes |
| Japanese Hiragana/Katakana | 1 byte |
| Japanese Kanji | 2 bytes |
| Control codes | 4 bytes |

### Tips for Fitting Translations

1. **Use shorter synonyms** where meaning is preserved
2. **Split long lines** with `\n` for readability
3. **Abbreviate** common terms when context is clear
4. **Check truncation count** in the script output

## Testing the Patched Files

To test in a PS1 emulator:

1. Copy the patched files to your game directory:
   ```bash
   cp output/patched/S100_KR.STG /path/to/game/S100.STG
   cp output/patched/COMM_KR.IMG /path/to/game/COMM.IMG
   ```

2. Load the game in your emulator (e.g., DuckStation, ePSXe)

3. Play through the S100 stage to verify Korean text displays correctly

## Troubleshooting

### "Missing glyph PNGs" Warning

Run the font generator first:
```bash
python python/font/generate_korean_font.py
```

### Korean Characters Display as Garbage

- Verify `COMM_KR.IMG` was copied to the game directory
- Check that the correct font file is being loaded

### Text Appears Cut Off

The translation exceeded the original text length and was truncated. Shorten the Korean translation or use abbreviations.
