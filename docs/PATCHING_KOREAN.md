# Korean Patching Guide - Arc the Lad 2

This document explains how to apply Korean translations to Arc the Lad 2 game files.

## Overview

The patching process involves two files:
1. **COMM.IMG** - Font texture containing character glyphs
2. **S*.STG** - Stage files containing dialogue text

**IMPORTANT:** Use `patch_all.py` instead of `patch_korean.py` when patching multiple files. See the main `PATCHING.md` document for why this is critical.

## Prerequisites

1. **Python 3** with Pillow library:
   ```bash
   pip install Pillow
   ```

2. **Korean font glyphs** (pre-generated):
   ```
   output/font/korean/chars/char_XXXX.png
   ```
   These are 12x12 pixel Hangul glyph images generated by `python/font/generate_korean_font.py`.

3. **Translation file**:
   ```
   translated/ko/S100_STG.txt
   ```
   Korean translations in the standard format (see Translation File Format below).

## Usage

### Recommended: Patch All Files Together

```bash
cd atl2_korean_translation
python python/patch_all.py
```

This creates a unified character mapping across all translation files and patches everything at once. This is the **only correct way** to patch multiple STG files.

### Single File (NOT recommended for multiple files)

```bash
python python/patch_korean.py S100
```

**WARNING:** If you patch S100, then SG00 separately, the second run overwrites COMM.IMG and loses characters unique to S100. Always use `patch_all.py` when working with multiple translation files.

### Dry Run (Test Without Writing)

```bash
python python/patch_korean.py S100 --dry-run
```

### Output Files

After patching, the following files are created in `output/patched/`:

| File | Description |
|------|-------------|
| `S100.STG` | Patched stage file with Korean dialogues |
| `COMM.IMG` | Font texture with Korean glyphs |
| `S100_charmap.txt` | Korean character → charID mapping |

## Font Slot Allocation

The patching preserves certain character slots and replaces others:

| CharID Range | Original Content | Action |
|--------------|------------------|--------|
| 1-80 | Hiragana (あ-っ) | **Replaced** with Korean |
| 81-160 | Katakana (ア-ッ) | **Replaced** with Korean |
| 161-186 | Latin A-Z | **Preserved** |
| 187-212 | Latin a-z | **Replaced** with Korean (priority: packed list chars) |
| 213-222 | Digits 0-9 | **Preserved** |
| 223-238 | Symbols (、。！？ etc.) | **Preserved** |
| 239+ | Kanji | **Replaced** with Korean |

This allows up to ~1,800 unique Korean characters (185 single-byte + ~1,600 two-byte) while keeping uppercase Latin letters, numbers, and punctuation intact. Lowercase a-z (charIDs 187-212) were verified to be unused as standalone bytes in visible game text and are repurposed for Korean to reduce byte usage in packed item lists.

## Translation File Format

Translation files follow this format:

```
0x000B4516 [0x8006] [script:16 07]큰 도시네
0x000B4564 [0x8006] [script:44 07]알디아의 수도니까,[delay:15]그래서
--- context: 0x8006 -> 0x8005 ---
0x000B45C8 [0x8005] [script:72 07]여기가 내 아파트야
```

### Format Breakdown

| Component | Description |
|-----------|-------------|
| `0x000B4516` | File offset of the dialogue |
| `[0x8006]` | Speaker/context opcode |
| `[script:16 07]` | 2-byte event script prefix (preserved as-is) |
| Korean text | The translated dialogue |

### Supported Control Codes

| Tag | Bytes | Description |
|-----|-------|-------------|
| `[br]` | `FF 05 01 01` | Line break |
| `[delay:XX]` | `FF 03 XX 01` | Text delay (XX = hex frame count) |
| `[box:system]` | `FF 08 01 01` | Open system text box |
| `[box:speech]` | `FF 08 03 01` | Open character speech box |
| `[box:close]` | `FF 08 02 01` | Close dialogue box |
| `[cursor]` | `FF 08 07 01` | Page break with cursor (adds 4 bytes - see warning) |
| `[opt]` | `EF` | Choice option prefix |

## Packed Item Lists

SCPS_100.26 and BEAM.DAT store multiple item names in packed lists, separated by FF control codes:

```
소드[FF:1A 00 00]블레이드[FF:1A 00 00]에지[FF:1A 00 00]검
```

### Separator Preservation and Item Padding

The patcher preserves original separator bytes **verbatim** from the binary. Each Korean item is padded with charID 160 (byte `0xA0`, blank glyph) to match the original item's exact byte length.

| File | Separator opcode | Translation tag |
|------|-----------------|-----------------|
| SCPS_100.26 | `FF 1A` | `[FF:1A 00 00]` |
| BEAM.DAT | `FF 19` | `[FF:19 00 00]` |

**How it works**: `parse_original_packed_list()` scans the original binary at the entry offset to find item boundaries and separator bytes. Each Korean item is encoded, then padded/truncated to match the original item's byte count. Separator bytes are copied from the original binary without modification.

**Translation tags** (`[FF:1A 00 00]` / `[FF:19 00 00]`) in translation files are used only as delimiters to split the Korean text into items. The actual bytes written to the binary come from the original.

### Original Text Compression

The original Japanese uses FF prefix codes as text compression macros:
```
[FF:16 5F E3]ド    → renders as ソード (Sword)
[FF:1B F1 6D]草    → renders as 薬草 (Herb)
```

Korean translations replace these with full text (`소드`, `약초`). The game renders flat text correctly without prefix codes.

## Text Length Constraints

The game uses fixed-length dialogue slots. If a Korean translation is longer than the original Japanese text, it will be **truncated** to fit.

### Byte Comparison

| Character Type | Bytes |
|----------------|-------|
| Korean Hangul (charID 1-159, 187-212) | 1 byte |
| Korean Hangul (charID 239+) | 2 bytes |
| Japanese Hiragana/Katakana | 1 byte |
| Japanese Kanji | 2 bytes |
| Control codes | 4 bytes |

### Tips for Fitting Translations

1. **Use shorter synonyms** where meaning is preserved
2. **Abbreviate** common terms when context is clear
3. **Check truncation count** in the script output
4. **Use `find_truncated.py`** to identify dialogues that need shortening:
   ```bash
   python python/find_truncated.py S100 --output truncated.txt
   ```

### WARNING: `[cursor]` Does NOT Help Truncation

The `[cursor]` tag (FF 08 07 01) adds 4 bytes to the text - it makes it **longer**, not shorter. Do NOT use `[cursor]` to try to fit long translations.

The `[cursor]` tag is only useful when:
- The original Japanese already has page breaks
- You have spare space and want dramatic pauses

## Testing the Patched Files

To test in a PS1 emulator:

1. Copy the patched files to your game directory:
   ```bash
   cp output/patched/S100.STG /path/to/game/S100.STG
   cp output/patched/COMM.IMG /path/to/game/COMM.IMG
   ```

2. Load the game in your emulator (e.g., DuckStation, ePSXe)

3. Play through the S100 stage to verify Korean text displays correctly

## Troubleshooting

### "Missing glyph PNGs" Warning

Run the font generator first:
```bash
python python/font/generate_korean_font.py
```

### Korean Characters Display as Garbage

- Verify `COMM.IMG` from `output/patched/` was copied to the game directory
- Check that the correct font file is being loaded

### Text Appears Cut Off

The translation exceeded the original text length and was truncated. Shorten the Korean translation or use abbreviations.
